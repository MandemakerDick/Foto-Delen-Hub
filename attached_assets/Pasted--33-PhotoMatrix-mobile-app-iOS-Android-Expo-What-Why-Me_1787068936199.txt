#33 - PhotoMatrix mobile app — iOS & Android (Expo)
What & Why
Members currently use PhotoMatrix through a browser. A native Expo app lets photographers browse the gallery, view and like photos, leave notes, and upload their own shots directly from their phone — and makes the community accessible to a wider audience through the App Store and Google Play.

PhotoReviewHub is out of scope. This task covers PhotoMatrix only.

Platform
Framework: Expo (React Native) — Replit has first-class support for developing Expo apps
Stores: Apple App Store (iOS) + Google Play (Android)
Build / submission: Expo EAS (cloud build service) — binaries are built outside Replit and submitted to the stores by the project owner
Apple Developer Program: €99/year required before submission
Google Play: €25 one-time registration
Architecture
New artifact at artifacts/photoclub-mobile/ (Expo, slug photoclub-mobile)
API: same @workspace/api-server backend — no changes needed
API client: reuse @workspace/api-client-react (TanStack Query hooks work in React Native)
Auth: Clerk via @clerk/clerk-expo (the existing Clerk tenant works on mobile with Expo's PKCE OAuth flow)
Navigation: Expo Router (file-based, analogous to Next.js App Router)
Styling: NativeWind (Tailwind utility classes on React Native components) to stay close to the web palette
i18n: react-i18next — reuse the existing en.json / nl.json translation files from the web app

API surface used
All operations hit the existing API server. No new endpoints are required for v1. Key calls:

GET /api/photos, GET /api/photos/:id, GET /api/photos/recent
POST /api/photos (upload), PATCH /api/photos/:id (edit), DELETE /api/photos/:id
POST /api/photos/:id/like
GET /api/photos/:id/comments, POST /api/photos/:id/comments, DELETE /api/photos/:id/comments/:cid
GET /api/clubs, GET /api/clubs/:id
GET /api/themes, GET /api/themes/:id
GET /api/photographers, GET /api/photographers/:id
GET /api/search
GET /api/stats
GET /api/me, POST /api/me/link, PATCH /api/me/profile
POST /api/storage/uploads/request-url + direct S3 upload
POST /api/invites/redeem
GET /api/themes/my-proposals
Done looks like
The Expo app runs in Replit preview (Expo Go / dev client)
A member can: browse the gallery, open a photo, like it, post a comment
A signed-in member can: upload a photo from their camera roll, edit their own photos
A new member can: redeem an invite link and link their Clerk account
The app matches PhotoMatrix's visual identity (dark theme, serif headings, red accent)
Both English and Dutch are selectable
EAS build config (eas.json) is included so the owner can run eas build to produce store-ready binaries
